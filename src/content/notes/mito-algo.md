整理自硕士学位论文《线粒体超分辨显微图像分析方法研究》的方法主线：图像处理 → 实例分割 → 多维特征 → 定量评估。所有参数与流程均在实际项目中跑通，可按此复现。

### 一、图像处理：把高噪声超分辨图像拉回可比较的基线
- 原始数据为超分辨显微图像，噪声高、对比度低，直接分割必然失败
- 流程：去噪 → 灰度归一化 → CLAHE 对比增强，压制噪声的同时保住线粒体的纤细分支
- 批处理：用 Python 调用 FIJI / ImageJ 跑统一预处理流程，训练集与验证集同一口径，避免人工操作引入偏差
- 踩坑：全局直方图均衡会把噪声一起放大，换 CLAHE 限制对比度后才稳定

### 二、实例分割：把 SAM 改进成 MitoSAM
- 原 SAM 参数：patch_size 16×16、encoder_depth 32、embed_dim 1280、num_heads 16
- 结构改进：
  - ViT 主干深度扩展，注意力头增至 36 个（前 8 层 8 头看整体形态、中 16 层 12 头平衡计算与精度、后 8 层 16 头抠细节纹理，另加跨尺度注意力 4 头关注 [2,4,8,16] 倍下采样特征）
  - 局部-全局混合注意力，并用门控注意力替换标准自注意力
  - 编码器第 8 / 16 / 24 / 32 层后加跳跃连接，引入 FPN [256, 512, 1024, 1280] 做多尺度融合
  - 追加 2 个轻量线粒体形态先验卷积（3×3 与 5×5，通道 64 / 128）
- 半监督范式：先以 2045 个标注线粒体训练 50 个 epoch 生成伪标签（置信度 > 0.85 才收），再不确定性采样每轮补标 100–300 个困难样本，累计约 3000 个后训练 100 个 epoch
- 结果：Dice 达到 MoDL 等专用模型同等水平，但人工标注仅 120 个视野 / 2045 个线粒体

### 三、多维特征提取：174 维 → 30 维
- 形态学：面积、周长、纵横比、圆度等，描述线粒体的基本形状变化
- 纹理：GLCM（对比度 / 同质性 / 相关性 / 能量）+ LBP（熵 / 能量），捕捉内部嵴结构的细微差异
- 空间分布：Ripley's K / L 函数及 AUC、Voronoi 图、最近邻距离，量化线粒体网络的聚集与分散
- 筛选：全部特征标准化后，用随机森林重要性排序，从 174 维中取最重要的 30 维，既避免维度灾难又保留可解释性

### 四、定量评估：随机森林投票 → 异常指数
- 样本：40 行（样本）× 174 列（特征），对照 / 实验各 20；按图像编码分层抽样划分训练与验证，防止同一图像的多条线粒体样本泄漏
- 模型：200 棵决策树并行投票，异常指数 = 投票为异常的树占比（predict_proba），是连续可解释的输出
- 阈值：动态阈值 0.192；40 个验证样本仅 2 例误判
- 对比：在 RandomForest / LogisticRegression / XGBoost / LightGBM 四个分类器下，本方法多维特征的 AUC 分别为 0.971 / 0.990 / 0.974 / 0.959，均为对比中最优，且泛化差距小
- 可解释性：用 SHAP 边际贡献绘制特征重要性报告，说清楚「为什么判异常」
